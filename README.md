# Knotbase

Knotbase is an incremental, public distribution of original, indexed AI instruction workflows.

## Current status

**Source publication in progress — not a functional release.** The first four batches comprise 45 canonical instruction, index and template files across code, GitHub, research and papers: 44 copied verbatim, and one paper catalogue template with a single privacy-only heading replacement ([documented here](docs/PRIVACY_ADAPTATIONS.md)). No algorithms or procedural contracts were rewritten. These selected modules contain no personal profile or contact details, private filesystem paths, or bundled third-party media. Canonical Git blob checksums and publication status are recorded in `manifests/source_parity.csv`.

The research domain contains its original core, index, eight workflows and template. The papers domain contains its original index, nine workflows and a privacy-neutralized entry template. The global `AGENTS.md`, cross-domain routing registry, command dispatcher, code/GitHub cores and remaining modules are **not yet installed**. Cross-references that require those absent files will become operational only once their prerequisites have been migrated, reviewed for privacy, and validated. Do not interpret these files as a working command runtime or claim full parity.

Every future instruction, schema, and algorithm must preserve the canonical source exactly, except for small, documented changes required for privacy. No summaries, rewritten algorithms or approximated contracts are accepted as replacements.

The personal CV template and Europass are not part of this publication. No user data or review archives are included.
