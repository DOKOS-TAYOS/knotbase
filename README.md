# Knotbase

Knotbase is an incremental, public distribution of original, indexed AI instruction workflows.

## Current status

**Source publication in progress — not a functional release.** The published batches comprise 75 source files across code, GitHub, research, papers and education: 73 copied verbatim and two files with individually documented privacy-only substitutions ([documented here](docs/PRIVACY_ADAPTATIONS.md)). No algorithms or procedural contracts were rewritten. These selected modules contain no personal profile or contact details, private filesystem paths, or bundled third-party media. Canonical Git blob checksums and publication status are recorded in `manifests/source_parity.csv`.

The education domain contains its original core, index, instructional workflows, audience profiles and note-writing modules. The research domain contains its original core, index, eight workflows and template. The papers domain contains its original index, nine workflows and a privacy-neutralized entry template. The global `AGENTS.md`, cross-domain routing registry, command dispatcher, code domain index and repository-identity module, GitHub core, and remaining modules are **not yet installed**. The code core is present as a source-only partial migration. Cross-references that require those absent files will become operational only once their prerequisites have been migrated, reviewed for privacy, and validated. Do not interpret these files as a working command runtime or claim full parity.

Every future instruction, schema, and algorithm must preserve the canonical source exactly, except for small, documented changes required for privacy. No summaries, rewritten algorithms or approximated contracts are accepted as replacements.

The personal CV template and Europass are not part of this publication. No user data or review archives are included.
