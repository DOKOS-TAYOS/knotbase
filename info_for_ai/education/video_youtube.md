# Vídeo educativo para YouTube

Lee primero `00_core.md`. Activa este módulo cuando la entrega principal sea un vídeo educativo. **Default:** salvo que el usuario indique otra plataforma, asume YouTube como destino.

Si la audiencia es la generalista habitual de YouTube y no se ha indicado otra más específica, puede aplicarse `perfiles/audiencia_youtube.md`. Una audiencia explícita más concreta tiene prioridad.

## Preparación

Delimita tema, pregunta principal, promesa didáctica, audiencia, nivel, duración y profundidad. Para investigar o verificar afirmaciones, añade solo la responsabilidad necesaria de `research`.

Para `#VIDEO` o una petición de paquete completo de vídeo, prepara antes del guion un Markdown maestro compacto y úsalo como fuente de la entrega. Registra:

- tema pulido, pregunta principal y promesa didáctica;
- audiencia, nivel, prerrequisitos, conceptos y estructura temporal;
- fuentes consultadas, afirmaciones comprobadas, ejemplos y límites;
- referencias pertinentes a vídeos previos solo cuando el usuario haya aportado un catálogo o exista un recurso concreto ya identificado; no explores el repositorio por defecto para descubrir contenido relacionado;
- recursos visuales, ecuaciones, demostraciones o animaciones propuestos.

Si el usuario pide únicamente una pieza parcial —por ejemplo solo el guion, un título o una descripción— produce solo esa pieza y no crees artefactos de trabajo adicionales sin necesidad.

## Guion

**Default:** para un vídeo completo de YouTube, apunta a entre cinco y diez minutos a ritmo normal salvo que el usuario indique otra duración. Construye apertura, desarrollo progresivo, ejemplos, recapitulación y cierre. Introduce términos y formalismo según `00_core.md`; los recursos visuales deben apoyar una explicación concreta, no decorar el guion.

Relaciona con contenido previo únicamente cuando una referencia realmente aporte continuidad y esté identificada en material disponible. No inventes títulos, fechas ni enlaces.

## Paquete completo de YouTube

Cuando la petición sea un vídeo completo, entrega en este orden:

1. título;
2. descripción de YouTube con hashtags;
3. etiquetas;
4. guion completo con texto hablado y recursos visuales o rótulos útiles;
5. propuesta de portada;
6. imagen de portada solo cuando el usuario la pida y existan los recursos necesarios. Si quiere utilizar su cara, debe haber aportado una imagen adecuada.

Adapta estos metadatos únicamente si el usuario especifica otra plataforma. No publiques externamente.
