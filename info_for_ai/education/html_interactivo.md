# HTML educativo interactivo

Lee primero `00_core.md`. Activa este módulo cuando la interacción web forme parte material del aprendizaje. Este módulo decide el contenido y la función didáctica; `htmls/` controla implementación, responsividad, navegación, presentación y verificación técnica.

Cuando la tarea requiera construir el artefacto HTML, añade la responsabilidad `htmls`, abre su core e índice y selecciona solo el módulo de implementación necesario. Si la tarea se limita a diseñar la interacción pedagógica, no cargues `htmls/` todavía.

## Diseño didáctico

La experiencia debe funcionar, cuando corresponda, en dos contextos: acompañar una explicación oral y seguir siendo comprensible después cuando el alumno la explore por su cuenta.

Durante una exposición, la vista inicial debe permitir entender rápidamente qué relación, proceso o estructura se está explicando sin competir con el ponente mediante bloques densos de texto. Para uso autónomo, el alumno debe poder acceder a detalles, ejemplos, comparaciones o estados adicionales que aporten profundidad real.

**Default:** mantén la superficie inicial visualmente ligera. Prioriza diagramas, relaciones, ejemplos, estructuras comparativas, estados manipulables y texto breve directamente visible. Usa revelado progresivo —desplegables, tabs, detalles, pasos, controles o paneles— solo cuando organice mejor la comprensión y no esconda información imprescindible para seguir el concepto básico.

Reduce texto cuando una representación visual explique mejor la relación, pero no sustituyas una explicación necesaria por decoración ni ocultes información esencial detrás de interacciones innecesarias.

## Interacción

Usa controles de parámetros, simulaciones, comparaciones, revelado progresivo o modelos manipulables solo cuando permitan comprender mejor un cambio de estado, dependencia, proceso o estructura que sería peor explicar de forma estática.

Cuando haya que inspeccionar un objeto espacial, prioriza un modelo 3D manipulable únicamente si la tercera dimensión aporta comprensión material. Toda interacción debe responder a una pregunta didáctica concreta y conservar una alternativa comprensible para el estado inicial.
