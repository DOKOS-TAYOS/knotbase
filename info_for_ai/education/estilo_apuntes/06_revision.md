# Revisión de apuntes

Aplica esta lista al borrador final. Corrige los fallos detectados antes de entregar.

## Arquitectura y autonomía

- [ ] El capítulo explica por qué importa, para quién está escrito, qué presupone, qué cubre y qué deja fuera.
- [ ] Cada sección elimina una barrera, prepara una definición, enseña una operación, delimita una validez o conecta con práctica; no aparece solo porque «toca» en un índice.
- [ ] Las transiciones muestran por qué una sección habilita la siguiente.
- [ ] El cierre expresa capacidades adquiridas, simplificaciones, límites y un siguiente paso; no se limita a enumerar temas.
- [ ] El lector termina menos dependiente del propio texto.

## Intuición, formalismo y operaciones

- [ ] Las definiciones tienen una necesidad previa y una intuición útil antes del formalismo cuando corresponde.
- [ ] Toda intuición incompleta o analogía peligrosa incluye una corrección o límite.
- [ ] Cada símbolo está definido y cada ecuación importante tiene una interpretación en lenguaje natural.
- [ ] No aparecen matemáticas prematuras ni pasos no triviales presentados como si fueran inmediatos para el lector objetivo.
- [ ] Se explican las operaciones: entradas, salidas, tipos o dimensiones, significado y coste relevante.

## Ejemplos y representaciones

- [ ] El primer ejemplo es pequeño, calculable y aísla la estructura; un caso real posterior conecta con la práctica cuando procede.
- [ ] Los contraejemplos delimitan intuiciones sin abrir digresiones innecesarias.
- [ ] Figuras, tablas y representaciones responden a una pregunta concreta y no son decorativas.
- [ ] Las traducciones entre ecuación, diagrama, geometría o implementación se enseñan en ambas direcciones cuando aportan comprensión.

## Calibración

- [ ] Las afirmaciones fuertes declaran condiciones y separan ventajas teóricas de prácticas.
- [ ] «Eficiente», «mejor» o expresiones semejantes identifican recurso, métrica, comparación y régimen.
- [ ] Se distinguen limitaciones pedagógicas, matemáticas, computacionales, estadísticas, físicas, experimentales, de hardware, de software y del estado del arte cuando la diferencia importa.
- [ ] Los hechos consolidados no se confunden con resultados recientes, hipótesis, expectativas o líneas abiertas.
- [ ] Las salvedades se colocan donde cambian la interpretación, sin convertir cada frase en una defensa jurídica.

## Voz, terminología y recursos

- [ ] La voz es cercana y disciplinar, sin impersonalidad enciclopédica, coloquialidad excesiva, grandilocuencia ni tono promocional.
- [ ] El plural inclusivo acompaña el razonamiento sin ocultar pasos; la sintaxis mantiene claras las relaciones causales.
- [ ] Las listas condensan estructuras reales y la repetición cumple funciones pedagógicas distintas.
- [ ] Los términos técnicos y anglicismos útiles se presentan la primera vez y pueden buscarse después en la literatura real.
- [ ] Cada paper amplía, justifica, muestra un método o abre el siguiente nivel; no hay bibliografía ornamental.
- [ ] Cada herramienta se vincula con un objetivo, un tipo de usuario y una limitación; no hay listas de software sin criterio ni afirmaciones absolutas sobre «la mejor» opción.

## Prueba de poda

Para cada sección, pregunta: «Si la elimino, ¿qué barrera concreta reaparece para el lector?». Si no hay una respuesta clara, revisa su función, muévela o elimínala.
