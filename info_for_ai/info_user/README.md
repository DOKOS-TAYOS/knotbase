# User knowledge: empty portable template

This domain ships with no user facts. The index is the authoritative selection map. Only authorized records in the user's configured private knowledge store can supply facts for personal answers. Do not infer an identity, owner, publication, repository, achievement, or biography from this template.

Canonical CSVs are header-only in the public upstream. Derived Markdown views are intentionally empty; an empty view is not evidence of absence in the world. Preserve stable source identifiers, visibility and review status when maintaining records in a private instance.
