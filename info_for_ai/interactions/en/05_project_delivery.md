# Sending a promised project item in English

## Activation

Use this workflow when the note accompanying a promised item must be written in English, whether the item is a document, link, result, code, paper, contact, presentation, or something else.

## Content

Get to the delivery quickly: refer briefly to the commitment, identify what is being sent and where it is, and add a useful note only when needed. Do not reconstruct the project or describe in detail something the recipient already understands.

If there was a delay and the user wants to acknowledge it, do so in one sentence without dramatizing. Do not apologize when no delay or problem is known. Mention versions, limitations, or pending items only when relevant. If the recipient needs to act, state the requested action clearly.

## Channel and output

A new email may include a subject; keep the existing subject when replying in the project thread. On LinkedIn or messaging, two or three sentences with a minimal greeting and closing are usually enough.

Return a concise, send-ready note to accompany the promised material.
